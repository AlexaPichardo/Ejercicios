### Arreglo y bucles

**los arreglos**
*son una estructura de datos donde se almacenan multiples elementos que se ordenan en una especie de indice.*

**Caracteristicas**
*es de longitud dinamica,*
*se pueden almacernar cualquier tipo de datos (colores, numeros, nombres),*
*un arreglo contiene elemntos (longitud) y cada uno de estos ocupa una posicion diferente (indice).*

*Metodos Arreglo*

1. Push agrega un elemento al final del arreglo

2. Unshift agrega un elemento al inicio del arreglo

3. Pop elimina el ultimo elemento del arreglo

4. Shifth elimina el primer elemento del arreglo

5. Map cambia todos los elementos por el nuevo elemento del arreglo
